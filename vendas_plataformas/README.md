# Vendas por plataformas digitais

Esta pasta guarda procedimentos comerciais para vender o App Orçamento Familiar em plataformas como Kiwify, Hotmart, Eduzz ou similares.

## Estrutura recomendada

- `kiwify/`: tutorial e checklist para venda pela Kiwify.
- Outras plataformas podem ganhar pastas próprias seguindo o mesmo modelo.

## Regra comercial principal

O cliente deve receber acesso quando o pagamento estiver aprovado pela plataforma, não quando o dinheiro estiver disponível para saque na sua conta.

O prazo de liberação de saldo é uma regra financeira entre a plataforma e o produtor. A entrega do produto deve seguir o status da venda aprovada.
